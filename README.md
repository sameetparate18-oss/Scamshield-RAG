# 🛡️ ScamShield-RAG

An Enterprise Cyber Fraud Intelligence & Threat Forensics Workstation powered by multi-vector RAG retrieval, 5-axis manipulation decomposition, and native Bharat-QR/Quishing inspection.

## 🚀 Features
- **Multi-Vector Semantic RAG:** Cosine similarity retrieval against indexed cybercrime advisories (Interpol, CERT-In, FBI IC3, Europol).
- **5-Axis Weaponization Radar:** Visual decomposition of psychological urgency, impersonation, and diversion tactics.
- **Bharat-QR & Quishing Lab:** Native OpenCV parsing of NPCI UPI parameters (`upi://pay`), issuing PSP detection, and malicious URL redirect isolation.
- **Multimodal Ingestion:** Handles raw communication text, optical screenshots, and call recordings.
